# kingpoppy.com

Static rebuild of the former Carrd site for GitHub Pages.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

## GitHub Pages

1. Push this folder’s contents to `finnious/kingpoppy` (`main`, site root).
2. Settings → Pages → Deploy from branch `main` / `/ (root)`.
3. Custom domain: `www.kingpoppy.com` (and/or apex).
4. At name.com: apex A → `185.199.108–111.153`; www CNAME → `finnious.github.io`.
5. Enforce HTTPS after DNS verifies. Detach Carrd last.
